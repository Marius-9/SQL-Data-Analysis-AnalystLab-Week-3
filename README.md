# SQL Data Analyst - Week 3

## Project Overview

This repository contains SQL analysis projects completed during Week 3 of my Data Analyst training.

The objective of this project was to explore, clean, and analyze datasets using Microsoft SQL Server and T-SQL in order to generate meaningful business insights.

## Projects

### 1. Chinook Database Analysis

Analysis of the Chinook database to explore music store data, including customers, artists, albums, tracks, invoices, and sales.

Key SQL concepts used:
- SELECT statements
- Filtering with WHERE
- Aggregations
- GROUP BY
- JOIN operations
- Subqueries

### 2. Sales Data Analysis

Analysis of a sales dataset to understand business performance and identify key trends.

Main analyses:
- Total revenue
- Average sales
- Sales by product line
- Sales by country
- Sales trends over time
- Top customers
- Best-selling products
- Order status analysis

## Tools Used

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL
- GitHub

## Skills Demonstrated

- Data exploration
- Data cleaning
- Data transformation
- SQL querying
- Business analysis
- Insight generation
